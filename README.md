# Portfolio Agence Digitale - IgoTech

## 📝 Présentation du Projet

Ce projet a été réalisé dans le cadre du cours de **Génie Logiciel** (Niveau II - Génie Informatique). L'objectif est de concevoir et de développer un portfolio numérique pour l'agence de communication digitale **"IgoTech"**.

L'agence souhaite mettre en avant ses réalisations, présenter ses services et faciliter la prise de contact avec ses futurs clients grâce à une interface moderne, fluide et responsive.

## 🚀 Fonctionnalités

*   **Accueil Dynamique** : Présentation de l'agence avec un appel à l'action clair.
*   **Présentation des Services** : Détail des prestations (Web, Social Media, Marketing).
*   **Galerie de Projets** : Exposition des réalisations avec effets visuels au survol.
*   **Témoignages Clients** : Mise en avant de la satisfaction client pour renforcer la confiance.
*   **Design Responsive** : Site entièrement optimisé pour ordinateurs, tablettes et smartphones.
*   **Formulaire de Contact** : Interface simple pour la collecte de prospects.

## 🛠️ Technologies Utilisées

Pour garantir la légèreté et la maintenabilité du projet, nous avons utilisé les technologies web standards :

*   **HTML5** : Structure sémantique et accessibilité.
*   **CSS3** : Mise en page moderne (Flexbox/Grid) et animations.
*   **JavaScript** : Interactions dynamiques et gestion du menu mobile.
